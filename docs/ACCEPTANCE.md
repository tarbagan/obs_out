# Приёмка на Windows 11 с DeckLink SDI 4K

Статус: **не выполнена — на машине разработки платы нет**.
Запишите версии OBS, Desktop Video, модель/ID платы, профиль, драйвер GPU,
тип SDI-монитора, режим и версию прошивки платы при наличии.

| Проверка | Ожидаемый результат |
|---|---|
| OBS без Desktop Video | Понятное предупреждение в журнале, OBS не аварийно завершается |
| Desktop Video установлен, платы нет | Нет вымышленных устройств/режимов, OBS продолжает работу |
| Плата установлена | Совпадают модель, persistent ID, SDI input/output с Desktop Video Setup |
| Одинаковые платы | Различаются постоянные идентификаторы и выбор устройства |
| Вход SDI без сигнала | Нет ложного утверждения о lock, журнал показывает потерю при получении соответствующего кадра |
| Вход 1080p25 → 1080p50 | Auto определяет изменения, если этот режим поддерживается драйвером |
| Отключение/возврат входного кабеля | Журнал фиксирует переходы, захват восстанавливается |
| Program 1080p25 | SDI-анализатор подтверждает режим, изображение совпадает с Program |
| Переключение сцен | На SDI видны переходы и изменения Program |
| Preview | Отдельно проверяется маршрут Preview; один аппаратный выход не назначается двум потокам одновременно |
| Звук | Stereo 48 kHz, оба канала, проверка A/V sync тестом хлопка/вспышки |
| 29.97 против 30 | Неподходящий FPS не запускается с сообщением об ошибке |
| Сохранённый режим недоступен | Нет падения; требуется повторный выбор режима |
| Устройство занято Media Express | Неудачный запуск не оставляет частично включённый выход |
| Повторный Start/Stop 50 раз | Нет зависания, накопления ресурсов и потери возможности запуска |
| Работа 60 минут | Контроль памяти, A/V sync, отсутствия постоянных пропусков анализатором |
| Остановка/выход из OBS | Выход освобождён; Media Express может использовать плату |
| 2160p25/29.97/30 | Испытывать только режимы, подтверждённые SDK для конкретного pixel format |
| Reference отсутствует/подключён | Статус reference соответствует драйверу; отсутствие reference не путается с потерей video input |

Изменение активного профиля и потеря устройства во время вывода требуют отдельного
стресс-теста; автоматическое восстановление выхода пока не реализовано.
При ошибке сохраните полный OBS log, снимок диагностических свойств и результат
измерения SDI-анализатором. Одного изображения preview OBS для приёмки недостаточно.
