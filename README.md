# OBS Out — DeckLink SDI 4K

Проект нативного плагина для **Windows 11 x64 и OBS Studio 32.2.2**.
Назначение: захват SDI и передача Program/Preview из OBS на аппаратный SDI OUT.
Основа — модули `decklink` и `decklink-output-ui` OBS Project с собственными
проверками и диагностикой. Успешная CI-сборка подтверждает компиляцию; работу с платой нужно проверить отдельно.

## Возможности

- Обнаружение устройств через DeckLink Discovery, имена и постоянные идентификаторы,
  входные/выходные режимы и доступные типы подключений.
- Захват Blackmagic Device, автоматическое определение входного формата при поддержке
  платы, журналирование появления/потери сигнала.
- Окно **Tools → DeckLink Output**: отдельные настройки Program и Preview,
  запуск/остановка аппаратного выхода, встроенный звук stereo 48 kHz.
- Диагностика в свойствах выхода: capture/playback interfaces, SDI IN/OUT,
  subdevice, входной lock, обнаруженный формат, текущий выходной формат, reference lock.
  Кнопка **Refresh SDI diagnostics** делает снимок состояния всех устройств.
- Проверка SDI + видеорежима + формата пикселей через драйвер до запуска,
  проверка точного FPS, очистка ресурсов при частично неудачном старте.
- Обработка отсутствующего сохранённого режима и копирование видео с учётом шага строки.

Состояния, которые драйвер не сообщает, показываются как `unknown`, а не как отсутствие
сигнала. Список типов подключений не нумерует BNC-разъёмы.

## Плата и физическое подключение

У **DeckLink SDI 4K** один SDI-вход и один SDI-выход, отдельно reference-вход.
Это 6G-SDI плата; 2160p50/60 нельзя считать поддерживаемыми по одному названию «4K».
Список режимов и окончательное решение берутся из SDK установленного драйвера.
Для первого испытания используйте **1080p25**, затем проверяйте остальные режимы.
Подключайте монитор к **SDI OUT**, а не к reference или SDI IN.

## Сборка

Нужны Git, Python 3.10+, CMake 3.30+ и Visual Studio с компонентом
**Desktop development with C++**, MSVC x64/x86 и Windows SDK 10.0.20348+.
Для Visual Studio 2026 нужен CMake с поддержкой генератора VS 18.
Скрипт автоматически выбирает VS 2022 или VS 2026 по установленному C++ toolchain.
Зависимости OBS/Qt скачиваются CMake из официальных пакетов с проверкой хешей.
Плата и Desktop Video для компиляции не требуются.

```powershell
git clone https://github.com/tarbagan/obs_out.git
cd obs_out
python -m unittest discover -s tests -v
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

Только подготовить исходники, без компилятора:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1 -PrepareOnly
```

Исходники OBS закреплены в `upstream.lock.json`; архив проверяется SHA-256.
Из полного дерева OBS собираются только два DeckLink-модуля и нужные им библиотеки.
Изменяйте файлы в `plugins/`, а не сгенерированное дерево `.deps/`.
Результат сборки: `dist/obs-out-32.2.2-windows-x64/`.
Сборка не устанавливает DLL и не меняет установленный OBS.

## Испытание на компьютере с платой

1. Установите Blackmagic Desktop Video. Убедитесь, что плата видна в Desktop Video Setup.
2. Подготовьте отдельную тестовую копию OBS 32.2.2 и закройте её перед копированием DLL.
3. Сохраните оригинальные `decklink.dll`, `decklink-output-ui.dll` и их каталоги данных.
   Скопируйте содержимое `dist/obs-out-32.2.2-windows-x64/` в корень тестовой копии.
   Наши модули **заменяют одноимённые встроенные модули**. Не загружайте обе версии
   одновременно и не переименовывайте DLL для параллельной загрузки.
4. Запустите OBS; в Settings → Video выберите FPS 25. Добавьте цветовые полосы/текст.
5. Откройте Tools → DeckLink Output. Выберите плату и 1080p25, отключите keyer,
   включите Force SDR, нажмите Start для основного выхода.
6. Проверьте изображение и звук внешним SDI-монитором/анализатором.
   Статус output mode в SDK сам по себе не доказывает приём сигнала монитором.

Подробная проверка: [docs/ACCEPTANCE.md](docs/ACCEPTANCE.md).
Официальные материалы и границы реализации: [docs/DESIGN.md](docs/DESIGN.md).

## Статус проверки

На рабочем компьютере платы нет. Локально проверены подготовка дерева исходников
и тесты инструментов сборки. Результат компиляции DLL смотрите в GitHub Actions:
CI публикует Windows x64 артефакт только после успешной сборки.
Аппаратные испытания пока не выполнены.
HDR, многоканальный звук сверх stereo, бесшовное изменение профиля и автоматическое
восстановление выхода после удаления устройства не входят в проверенную версию.
Изменив профиль платы в Desktop Video Setup, остановите выход и перезапустите OBS.
